تبدیل لینک VPN به JSON برای v2rayNG

لینک‌ها را (هر خط یکی) پیست کنید ← تبدیل ← دانلود. همهٔ کارها فقط داخل مرورگر انجام می‌شود و هیچ داده‌ای ارسال نمی‌شود.

راهنما و محدودیت‌ها
  1. هر لینک به یک «کانفیگ کامل Xray» جداگانه تبدیل می‌شود (inbound سوکس روی 10808 و HTTP روی 10809 + outbound با نام proxy). نام لینک در فیلد remarks ذخیره می‌شود.
  2. اگر یک لینک تبدیل شود، فایل .json دانلود می‌شود؛ اگر چند لینک باشد، یک فایل .zip شامل یک JSON برای هر اتصال دانلود می‌شود (zip را در گوشی باز کنید).
  3. واردکردن در v2rayNG: دکمهٔ «+» ← واردکردن از فایل محلی (Import from local) و انتخاب فایل JSON؛ یا در هر کارت «کپی» را بزنید و «+» ← واردکردن از کلیپ‌بورد.
  4. پورت سوکس v2rayNG باید همان 10808 (پیش‌فرض) باشد؛ اگر در تنظیمات عوض کرده‌اید، مقدار port داخل JSON را هم عوض کنید.
  5. پشتیبانی‌نشده (با خطا و نمایش لینک اصلی گزارش می‌شود): Shadowsocks با plugin، رمزهای قدیمی SS (مثل aes-256-cfb)، انتقال quic، فرمت قدیمی vmess غیر JSON.
  6. کانفیگ سفارشی تنظیمات مسیریابی خود v2rayNG (مثل «دور زدن ایران») را نادیده می‌گیرد؛ به همین دلیل گزینهٔ «ایران مستقیم» قانون‌های domain:ir و geoip:ir را داخل خود JSON می‌گذارد. بعد از تغییر گزینه دوباره «تبدیل» را بزنید.
  7. پارامترهایی که تبدیل نشوند بی‌صدا حذف نمی‌شوند؛ به‌صورت هشدار زرد زیر همان لینک نمایش داده می‌شوند.
  8. گزینهٔ «آرایهٔ JSON» همهٔ کانفیگ‌ها را در یک فایل می‌گذارد؛ فقط نسخه‌های جدیدتر v2rayNG آن را می‌پذیرند و گزارش‌هایی از ترتیب معکوس/اشکال در remarks وجود دارد. ZIP امن‌تر است.
