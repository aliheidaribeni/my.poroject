# VPN Link → JSON (v2rayNG)

ابزار تک‌فایل و آفلاین برای تبدیل لینک‌های `vless://`، `vmess://`، `trojan://` و `ss://` به کانفیگ JSON قابل import در v2rayNG.

## استفاده
1. `vpn-link-to-json.html` را در مرورگر باز کنید.
2. لینک‌ها را (هر خط یکی) پیست کنید و «تبدیل» را بزنید.
3. «دانلود JSON» را بزنید (چند لینک ← فایل ZIP، یک JSON برای هر اتصال).
4. در v2rayNG: «+» ← واردکردن از فایل محلی (یا کپی JSON و واردکردن از کلیپ‌بورد).

## نکات
- هر لینک یک کانفیگ کامل Xray است (سوکس 10808، HTTP 10809). کانفیگ سفارشی تنظیمات مسیریابی v2rayNG را نادیده می‌گیرد، پس گزینهٔ «ایران مستقیم» (`domain:ir` و `geoip:ir`) داخل JSON قرار می‌گیرد.
- پشتیبانی‌نشده: SS با plugin، رمزهای قدیمی SS، انتقال quic، فرمت قدیمی vmess غیر JSON.
- همهٔ پردازش داخل مرورگر انجام می‌شود و چیزی ارسال نمی‌شود.

از پوشهٔ همین ابزار: `node test_converter.js`
